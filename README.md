# Global Superstore Sales Dashboard using Power BI

## 📊 Project Overview
This mini-project focuses on analyzing the Global Superstore sales dataset using Microsoft Power BI. The dashboard provides interactive visualizations to understand sales performance, profitability, customer behaviour, product categories, and regional sales trends.

## 🎯 Objectives
- Analyze total sales and profit performance.
- Identify top-performing products and product categories.
- Compare sales across different regions.
- Understand sales trends over time.
- Track important business KPIs using DAX measures.
- Build an interactive dashboard for business decision-making.

## 🛠️ Tools and Technologies
- **Microsoft Power BI** – Dashboard creation and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX (Data Analysis Expressions)** – Measures and KPI calculations
- **Global Superstore Dataset** – Sales data for analysis

## 📈 Dashboard Features
- KPI cards for Total Sales, Total Profit, Profit Margin, Total Customers, Total Orders, and Average Order Value.
- Sales analysis by product name.
- Sales trends based on order date.
- Category-wise sales comparison.
- Region-wise sales analysis.
- Interactive slicers for Region, Category, and Year.

## 🔍 Key Insights
The dashboard helps identify high-performing products, compare regional performance, analyze category-wise sales, and understand changes in sales over time. These insights can support better business planning and data-driven decision-making.

## 🚀 How to Use
1. Download or clone this repository.
2. Open the Power BI dashboard file (`.pbix`) in Microsoft Power BI Desktop.
3. Ensure the dataset is connected correctly.
4. Refresh the data if required.
5. Use the dashboard visuals and slicers to explore sales performance.
